# Tableau Sales KPI Dashboard

Interactive Tableau dashboard tracking sales, profit, order count and regional, category and ship-mode performance.

## Live Dashboard
[https://public.tableau.com/app/profile/hema.pimaple/viz/KPISDAshboard/Dashboard1](https://public.tableau.com/app/profile/hema.pimaple/vizzes)


## Project Overview
Built to practice Tableau dashboard design using the Superstore sales dataset. The dashboard gives a one-page view of business performance and lets users filter by year, segment, country and quarter.

## Key KPIs
| KPI | Value |
|---|---|
| Total Sales | 2,326,534 |
| Total Profit | 292,297 |
| Total Order Count | 10,194 |

## Key Insights
- **West** is the top region by sales, followed by East, Central and South.
- **Technology** is the highest-selling category (839,893), followed by Furniture (754,748) and Office Supplies (731,893).
- **Standard Class** is by far the most used ship mode, ahead of Second Class, First Class and Same Day.
- Profit margin is about **12.6%** (292,297 / 2,326,534).

## Dashboard Features
- KPI cards for sales, profit and order count
- Sales by region (bar chart)
- Sales by ship mode (bar chart)
- Sales by category (pie chart)
- Interactive filters: Year, Segment, Country/Region, Quarter

## Tools Used
- Tableau Public / Tableau Desktop
- Superstore sample dataset

## Dataset
Superstore is a public sample dataset commonly used for learning business analytics.
